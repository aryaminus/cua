# Evidence index

Generated by the tools, never hand-edited. Everything persisted here passed
through the redactor (no raw SSNs, card numbers, or amounts). Two generations
exist, both checked in:

- **The committed `*-live`, `discovery-live`, and `vet-guard` runs** came from
  real OpenRouter model runs (provenance in each `meta.json`). The committed
  matrix/escalation replay runs (`replay-success-*`, `replay-business-*`,
  `replay-hard-failure-*`, `replay-escalation-*`, `replay-stability`) were
  produced by `cua demo --part all` against the live artifact.
- **Regeneration:** `uv run cua demo --part all` (no key needed: replay,
  matrix, escalation, stability, plus a scripted offline discovery) reproduces
  the offline set; the README demo path reproduces the live runs
  (`discovery-live` via `cua discover`, replays via `cua replay`).
  Because the mock server port is shared with any local `cua serve`, fault
  phases boot their own servers on private ports and port-rewrite the
  artifact; replay dirs regenerated by the demo are equivalent re-runs of
  the committed live runs.

Files per run: `meta.json` (config, params, provenance), `steps/NNN.json`
(redacted observations, decisions/actions, guard verdicts, typed decision
JSON only, never the conversation history), `steps/*.png`
(failure + escalation screenshots), `result.json` (the typed replay result),
`run.log`, and `intervention.json` where an escalation occurred.
